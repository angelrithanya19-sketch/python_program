# Python Program

## 📌 About the Project

This is a simple Python program created to practice basic Python programming concepts. It helps beginners understand how Python code works and how to run a program.

## 🎯 Objective

The main objective of this project is to:

* Learn the basics of Python
* Practice variables and data types
* Understand input and output
* Improve problem-solving skills
* Learn how to run Python programs

## 🛠️ Technologies Used

* Python 3
* IDLE / VS Code

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Open the `.py` file.
4. Run the program using Python.

### Using Command Prompt

```bash
python filename.py
```
